# 📚 Estudo de CSS — Display

Projeto desenvolvido com **HTML e CSS** com o objetivo de estudar a propriedade `display` e entender seus principais valores e casos de uso.

## 🎯 Objetivo

Este projeto serve como material de estudo para praticar como diferentes valores de `display` alteram o comportamento e o posicionamento dos elementos HTML na página.

## 📌 Conteúdos estudados

- `display: block`
- `display: inline`
- `display: inline-block`
- `display: flex`
- `display: grid`
- `display: none`

### 💡 Breve explicação

A propriedade `display` define como um elemento será apresentado e como ele participará do fluxo do documento.

Por exemplo:

- **`block`** — ocupa toda a largura disponível e começa em uma nova linha.
- **`inline`** — ocupa apenas o espaço necessário e permanece na mesma linha que outros elementos.
- **`inline-block`** — combina características de `inline` e `block`.
- **`flex`** — facilita o alinhamento e a distribuição dos elementos em uma dimensão.
- **`grid`** — permite criar layouts organizados em linhas e colunas.
- **`none`** — remove o elemento da renderização da página.

## 🛠️ Tecnologias utilizadas
